1. プロジェクト概要

【コンセプト】

「予定（やくそく）」と「お金（出費）」と天気をひとつにまとめて、日々の暮らしをスマートにサポートするスケジュール管理アプリ。

【ターゲット】

日常の予定と出費を管理したい個人ユーザー向け

【開発言語・環境】

  • バックエンド（メインWebAPI）: Java (Spring Boot)
  • データベース: SQL (PostgreSQL または MySQL)
  • フロントエンド: HTML / CSS / JavaScript (Bootstrap, Chart.js)

2. サイト構成 (サイトマップ)

本サイトは、以下の画面および機能で構成されます。

  • ログイン画面
    • ログイン機能
    • 新規登録機能
  • ホーム画面（カレンダー）
    • 今日～1週間の簡易スケジュールおよび天気情報の表示
  • 予定管理画面
    • 予定の新規登録・編集
    • 予定お知らせアラーム機能
  • 家計簿・収支管理画面
    • 今月の収支入力・一覧画面（カレンダー形式）
    • 収支の分類管理画面
    • 月の出費額の管理・目標との比較分析（AIアドバイス）をテキスト形式で表示
    • 拡張予定 出費の今月・直近比較 of 表示は、積み上げ式進捗バー（横棒グラフ）に拡張予定

3. 機能要件

3.1 スケジュール・予定管理機能

  • カレンダー表示: 月表示 / 日表示の切り替え。スケジュール内容ごとに色分け表示を行う。
  • 日時選択: 「開始」・「終了」時間を15分単位で選択可能（ドラムロールボタン式）。タイトル内には開始時間のみ表示し、終了時間はタップ展開したメモ内に表示する。
  • 予定の入力方式: 開始時間とスケジュール内容を入力。タップ展開することで、終了時間と詳細なスケジュール内容が閲覧可能。
    • プリセット選択: よく使う予定（「出勤」「買い物」「食事会」など）を事前に登録しておき、ワンタップで呼び出す機能。
    • 自由入力: タイトル、メモを手入力可能（タイトルは5文字以内）。
  • アラーム・通知機能:
    • プリセット選択: 設定した時間（15分前・30分前・1時間前のみ）に通知を行う。
    • 通知方法: 通知内容の画面表示 ＋ アラーム音。
    • 稼働条件: サイトを開いている間は、指定時刻に画面表示（モーダル） ＋ アラーム音でお知らせする。
    • 拡張予定 プッシュ通知の送信機能への拡張を予定。

3.2 天気連携機能（ログイン時のみ更新）

  • 自動更新: バックグラウンド処理（定期実行）により、ユーザーがアプリを開かなくても天気情報を定期取得する（1週間分のみ）。
    拡張予定 バックグラウンド自動更新への拡張を予定。
  • 表示位置: 日付横スペースにそれぞれの天気アイコン・気温（最高/最低）・降水確率％を表示する。
  • 利用サイト: Open-Meteo (オープン・メテオ) を無料枠内で使用する。

3.3 家計簿・収支管理機能（専用カレンダー。画面切り替え表示）

  • 収支・予算設定: 月ごとの収入額および目標出費額を設定する。収入額は「＋」、出費額は「ー」で金額を表示する。
  • 出費入力・フィードバック:
    • 支出の登録（今月の目標出費額設定、現状の出費額との比較）を行う。
    • カテゴリ（固定費、食費、光熱費など）ごとの分類管理機能。
    • 出費額や傾向に応じて、キャラクターAI（やくそくん）からの一言コメントをテキスト形式で表示する。（例: 「今週は節約上手だね！」「ちょっと使っちゃったかな？」）
